🇫🇷 Description

SuperLeak est une page web qui organise des informations confidentielles sur des super-héros.
Les données proviennent de all.json et incluent : image, nom, nom complet, statistiques, race, genre, taille, poids, lieu de naissance et alignement.

Fonctionnalités principales :

Pagination dynamique (10, 20, 50, 100 ou tous les résultats, 20 par défaut)

Recherche interactive par nom (filtrage à chaque frappe)

Tri par colonne (ascendant/descendant, numérique ou alphabétique)

Affichage rapide et efficace, sans framework externe (React, Vue, etc.)

Toutes les données sont récupérées via fetch et manipulées avec JavaScript pur

🇬🇧 Description

SuperLeak is a web page that organizes confidential information about superheroes.
Data comes from all.json and includes: icon, name, full name, powerstats, race, gender, height, weight, place of birth, and alignment.

Key features:

Dynamic pagination (10, 20, 50, 100 or all results, default 20)

Interactive search by name (filtering on every keystroke)

Column sorting (ascending/descending, numerical or alphabetical)

Fast and efficient display using vanilla JavaScript (no frameworks)

Data fetched via fetch and handled entirely in JS
